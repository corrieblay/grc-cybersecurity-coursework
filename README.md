# GRC & IT Audit Coursework

Practical exercises completed as part of my Cybersecurity - GRC/IT Audit 
Training with YesYouCan Cybersecure, LLC.

## Contents

- GRC Practice Lab – Built a Control Register (35 controls) for a 
  fintech scenario, mapped controls across NIST CSF, ISO 27001, PCI DSS, 
  and SOC 2, and tracked a Control Lifecycle from Proposed through Retired 
  (including a Cloud Access Control Policy and Zero Trust Architecture).

- Required Project 1 – Demonstrated file integrity hashing (WinMD5), 
  symmetric (AES-256-GCM) and asymmetric (RSA) encryption, digital 
  signatures with audit trails (AdVerse Sign), HTTPS/browser security, 
  and WhatsApp's end-to-end encryption model.

- Weekly Exercise 1 – Explored the 3rdRisk GRC platform and its 
  control library features.

Each file includes screenshots, analysis, and reflections on what I 
learned from hands-on use of GRC and security tools.
